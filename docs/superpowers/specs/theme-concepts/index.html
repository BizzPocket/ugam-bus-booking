Five genuinely different themes (not recolors)

Concept 1

Mono Line

Flat, borderless surfaces separated only by hairlines and space. Tight grotesk type, tabular numbers, one cool accent. The "serious software" look — Linear / Vercel.

  • Surfaces: no card fills — 1px hairlines + whitespace
  • Type: tight Inter, uppercase micro-labels
  • Shape: small radii (8px), rules not boxes
  • Feel: precise, dense, engineered
